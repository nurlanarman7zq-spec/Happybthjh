Инструкция по развертыванию

1. Настройка Supabase Storage и Database

Зайдите в Supabase, создайте проект и выполните следующие действия:

  • В разделе Storage создайте публичный bucket с названием greetings-media.
  • В разделе SQL Editor выполните скрипт для создания таблицы: 
    {`CREATE TABLE greetings (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  photo_url TEXT NOT NULL,
  music_url TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);`}
  • Настройте политики RLS (Row Level Security): разрешите публичный INSERT и SELECT для таблицы greetings и публичный доступ для storage bucket.

2. Подключение ключей в коде

В начале файла App.jsx в объекте CONFIG укажите ваш SUPABASE_URL и SUPABASE_ANON_KEY.

3. Публикация на GitHub Pages

  1. Создайте репозиторий на GitHub.
  2. Соберите проект (если используется Vite: npm run build).
  3. Загрузите файлы в ветку gh-pages или настройте GitHub Actions для автоматической сборки.
  4. В настройках репозитория (Settings > Pages) включите GitHub Pages. Ссылки вида https://username.github.io/repo/?id=abc123xyz будут работать автоматически благодаря встроенному роутеру параметров!
